دليل مدير المنتج (Product Manager) ومهندس البرمجيات

الرؤية المعمارية، خريطة تدفق البيانات، هيكل قواعد البيانات، واستراتيجية عدم انقطاع الخدمة (Offline-First)

1. تصميم تجربة وواجهة المستخدم (UI/UX)

  • لوحة الألوان (Coffee Palette): اعتماد درجات الإسبريسو العميقة (#23140e و #3d251d)، والكراميل الدافئ (#d97706)، مع لمسات الكريمة والحليب (#fbf8f5) لخلق بيئة مريحة وشهية للعين.
  • الخطوط: خط Cairo العربي العصري المميز بوضوح الأرقام ومقروئيته السريعة في بيئة العمل السريعة، وخط Inter للترميز والإنجليزية.
  • الوضع الافتراضي: يدعم النمط الفاتح النظيف والنمط الداكن للعمل الليلي مع الحفاظ على التباين العالي (Contrast Ratio 4.5:1+).

2. هندسة العمل بدون إنترنت (Offline-First Architecture)

  • طريقة العمل: عند انقطاع الإنترنت، لا تتوقف العمليات مطلقاً! يتم توليد معرفات الطلبات محلياً باستخدام UUID v4 أو معرف تسلسلي محلي.
  • التخزين المحلي: حفظ الفواتير في طابور محلي (Local Sync Queue عبر IndexedDB/LocalStorage).
  • الطباعة الفورية: الطباعة الحرارية للفواتير تتم عبر شبكة الـ LAN المحلية (ESC/POS Printer) مباشرة دون الحاجة لأي خادم خارجي.
  • المزامنة التلقائية: فور عودة الاتصال، يطلق التطبيق مزامنة صامتة في الخلفية مع حل النزاعات (Conflict Resolution: Last-Write-Wins).

3. التقنيات المقترحة (Tech Stack)

تطبيقات الهواتف (iOS / Android):

Flutter أو React Native + WatermelonDB لسرعة أداء فائقة وقابلية العمل أوفلاين مع العتاد المحمول.

واجهة الويب ولوحة التحكم:

Next.js 14 (React) + Tailwind CSS أو Progressive Web App (PWA) مع Service Workers.

الخادم الخلفي (Backend):

Node.js (NestJS) أو Go مع WebSockets لربط شاشات التحضير (KDS) والكاشير في جزء من الثانية.

قواعد البيانات:

PostgreSQL + Prisma ORM، مع SQLite أو IndexedDB على الأجهزة المحلية.
